# Login Test Cases

## TC01 - Valid Login
Steps:
1. Enter valid username
2. Enter valid password
3. Click login

Expected Result:
User is redirected to dashboard

---

## TC02 - Invalid Password
Steps:
1. Enter valid username
2. Enter wrong password
3. Click login

Expected Result:
Error message displayed

---

## TC03 - Empty Fields
Steps:
1. Leave fields empty
2. Click login

Expected Result:
Validation errors shown
